# Synthetic filesystem superblocks

These 1 KiB ext4 and 4 KiB Btrfs superblocks were extracted from the disposable images
generated by `scripts/linux/make-fixtures.py` inside Debian 13 on 2026-09-11.
No user files or keys are included. They serve as independent Linux-generated input for
the filesystem policy tests. Mutations recompute checksums to reach the intended check.

Kernel: 6.12.107+deb13-amd64; cryptsetup 2.7.5. Image: 256 MiB, plaintext: 240 MiB.
Filesystem creation commands and oracle procedure are in the fixture generator.
